# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-06-05

- Initial public release.
- Added a Python MCP server for `.nbs` files.
- Added NBS v5-compatible binary read/write support.
- Added tools for metadata, note reading, summaries, validation, generation, editing, layer operations, CSV/JSON import/export, MIDI import/export, Markdown reports, command export, comparison, patching, and AI-friendly music analysis.
